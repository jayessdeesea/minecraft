# The watches

A watch keeps one thing on course, pass after pass, with nobody at the keyboard. One is built:

| Watch | Keeps on course | Run |
|---|---|---|
| [Garrison](garrison.md) | The running garrison, toward the goals the operator has set | By hand, pass after pass |

Watches on a clock - the garrison's as detectors with a model only on a trigger, and the refactor, profile, backlog and
eval watches - are [backlog/watches.md](../../backlog/watches.md). The profile and refactor passes are on the commit
count until then (docs/conventions.md).
