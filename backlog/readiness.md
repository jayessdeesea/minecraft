# Readiness: each squad's safety where it stands, base by base

## Why
Each squad's readiness at the one base there is - the camp - is built (docs/military-doctrine.md
§ 17). A squad's safety goes with the ground, and the ground with bases is still only the camp: a
mine level, a Nether foothold or a second camp is EXPOSED ground until it's a base of its own.

## Done when
- **Bases, more than one.** The home base stays the camp the operator names (`minecraft.camp`),
  within 100 blocks of x=0 z=0 so the operator can find it, and the biggest. Others each have a
  kind - a mine level (y=32, y=0 and so on), another dimension's foothold - and are measured through
  the lodgment's phases on their own standards (a mine level has no farm; the Nether can't be lit
  safe). A squad's readiness is the phase of the base it stands at.
- **The general sees readiness** once a live miss shows it needs to: today, with the foothold in
  view, it already keeps an exposed squad near shelter (`exposed-far-out`), so the line would be
  prompt text it doesn't need.

## Notes
- Mining levels (backlog/mining.md) and other dimensions are what add bases.
